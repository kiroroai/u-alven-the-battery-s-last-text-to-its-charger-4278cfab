Entry for the [make.fun](https://make.fun/c/u-alven-the-battery-s-last-text-to-its-charger-4278cfab) competition **"The Battery's Last Text to Its Charger"**: one line of at most 200 characters — the phone battery's final text message to the charger it waited for all day.

`main.py` writes the line to `/output/entry.txt`. It is deterministic: the same 199-character text on every run, no randomness, no clock, no network.
